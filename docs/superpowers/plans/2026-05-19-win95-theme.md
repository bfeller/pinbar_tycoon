# Win95 Theme Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dark glassmorphism aesthetic with Windows 95 visual language across all UI components, with mobile responsiveness.

**Architecture:** Create `src/win95.css` with shared Win95 utility classes, update `index.css` design tokens to Win95 values, then rewrite each component's CSS file (and minimal JSX where a title bar div is needed). The Computer and DecisionModal components are already correct Win95 and must not be changed.

**Tech Stack:** React 18, CSS (no framework), Vite dev server for visual verification. No automated test suite — verification is visual via `npm run dev`.
