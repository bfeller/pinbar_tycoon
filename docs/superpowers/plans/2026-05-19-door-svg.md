# Entry Door SVG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder green square + "DOOR" text on the bar floor with a top-down SVG door that shows as closed during BUILD/REPORT phases and open during RUNNING.

**Architecture:** Create a new `DoorSVG` component (matching the pattern of `BathroomSVG`, `KegeratorSVG`) that accepts an `isOpen` prop. Thread `dayState` from `App.jsx` → `GameGrid.jsx`, derive `isOpen = dayState === 'RUNNING'`, and render the SVG inside the door cell. Clean up the now-redundant door CSS.

**Tech Stack:** React 18, inline SVG, Vite dev server for visual verification.
