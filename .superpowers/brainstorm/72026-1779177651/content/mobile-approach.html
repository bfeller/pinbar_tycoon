Mobile: what happens to the game grid on small screens?

The grid is 750×500px. On a phone (390px wide) it won't fit. Three options:

A

Scrollable / pannable grid

The grid overflows and the player scrolls/pans around it. The UI chrome (TopBar, buttons) stays fixed. Simple to implement, feels like a real tycoon game on mobile.

B

Scale-to-fit (zoom out)

The grid shrinks to fit the viewport using CSS transform scale. Everything stays visible but cells get tiny on phone — might be hard to tap accurately.

C

Smaller cells on mobile

CELL_SIZE drops from 50px to ~32px on small screens (via CSS or a breakpoint). Grid becomes ~480×320px — fits on most phones. Machines/customers scale down proportionally.
